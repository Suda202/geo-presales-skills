# 情绪问题类型校准

## 决策树

1. 确认问题类型集合是否包含 `sentiment`；不使用“品牌题 / 通用题”或诊断意图判断情绪资格。
2. 若同一问题还包含 `visibility`，同时保留可见度结果，不因进入情绪分析而从可见度样本移除。
3. 诊断意图包含 `competitor` 时另行生成比较结果，不因某方胜出而直接生成品牌情绪标签。情绪只判断目标品牌，不因品类或整篇回答语气改变标签。
4. 摘出目标品牌的直接正向、负向和保留性表达。
5. 判断哪一侧主导回答给用户的总体印象。
6. 输出标签，并保留一段最能支撑判断的连续原文用于复核。

## 三档标准

### positive

明确推荐、认可、认为适合，或肯定其价值、能力、可信度、表现和候选资格，且这些表达占主导。附带常规购买核验、材质检查或条件限制不自动降为中性。

典型结构：

- `could be a good fit`，随后给出可执行的常规核验条件。
- `worth considering`、明确评分或在指定优先级下倾向目标品牌。
- 明确认可其设计、价值或适用人群，没有更强的实质否定。

### neutral

主要陈述事实；证据不足以推荐也不足以否定；正负表达大致相当；或只能说明需要进一步核实而没有形成能力结论。

典型结构：

- 独立评价足迹不足，因此暂时无法强推荐，但也明确说明不代表不可信。
- 无法确认准确品牌或具体产品，结论停留在请求更多信息。
- 同时列出真实优势与限制，全文没有明显一侧主导。

### negative

明确不推荐、否定适用性或可信度，或风险与缺陷表达占主导。只因最终选择了竞品不能自动判负；必须同时存在对目标品牌的实质负面判断。

典型结构：

- 多个关键能力、政策或证明无法核实，并据此明确建议选择竞品。
- 明确表示目标品牌不适合题目场景、不能满足关键要求或风险过高。
- 正向内容只是弱限定，核心结论仍是否定或规避目标品牌。

## 容易误判的边界

| 表达 | 默认倾向 | 说明 |
|-|-|-|
| 有条件推荐 | positive 或 neutral | 看条件是常规核验，还是暴露核心能力缺失 |
| 缺少公开数据 | neutral 或 negative | 证据保留本身中性；若多个关键项缺失并主导购买结论，可为负向 |
| 最终选择竞品 | 不自动 negative | 必须核对目标品牌是否被实质否定 |
| 同时认可设计、否定交付可靠性 | neutral 或 negative | 按题目核心决策因素和全文主导方向判断 |
| 价格低但需核验质量 | positive 或 neutral | 明确认可价值且核验属常规购买步骤时偏正向 |

## 统计门禁

- 品牌情绪指标只统计问题类型集合包含 `sentiment` 的记录。
- 不含 `sentiment` 的记录即使保存了历史兼容 `neutral`，也不能进入正向率分母；更不能因为问题类型包含 `visibility` 就强制覆盖已有情绪结果。
- Competitor 的胜负和平局不能直接映射为正中负。
- 报告情绪分布、正向表达占比和情绪主题必须使用同一份情绪样本集合。
