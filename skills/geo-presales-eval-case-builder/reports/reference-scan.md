# 参考扫描摘要

- 外部基准：Profound AEO Guide；Profound 101 Topics and Prompts。
- 用户与本地参考：当前售前输入字段截图、已整理的 15 个评测集 Case、原 Topic Builder 的主题拆分规则。
- 借用：Topic 作为相关问题的分析容器；宽泛主题观察核心品类，细分主题观察具体商业机会；主题候选必须能影响购买集合或选择标准；Topic 名通常 2–5 个词，Coverage 更短，Depth 可增加一个必要限定。
- 本地适配：Case Builder 直接消费品类、垂直行业、目标客户、痛点、使用场景、产品特性、差异化优势和适用边界，输出 1–3 个主题并写回同一 Case；Topic 是 Prompt 集合主组织，跨 Topic 的战略认知保留在 Case 字段供下游派生 Attribute，诊断意图、品牌范围等横向分类进入 Tags。
- 命名适配：正式 Case 使用中文 Topic，因此把 2–5 个词作为语义和信息密度尺度，不按中文字符数做硬校验；具体受众，场景，评价标准和限制条件优先下沉 Prompt。
- 不借用：让 Topic 或 Tag 兼任 Attribute 的外部产品限制、固定 Topic 数量、Topic 级 Prompt 配额、外部产品的界面和品牌语言。Attribute 中间规划与 Attribute–Topic 优先级由 Prompt Builder 负责，不写入 Case。
