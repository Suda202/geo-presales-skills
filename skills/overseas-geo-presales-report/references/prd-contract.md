# PRD V3.7 实现契约

本实现以飞书 PRD revision 2148 为基线，并冻结以下工程取舍。

## 适用范围

- 仅支持一个 Topic。
- 仅支持美国市场、英文、ChatGPT 单平台。
- 默认问题配额为 50 条：通用题 40 条、品牌题 10 条。
- 推荐、比较、决策三类都必须存在，但不设各自数量或六宫格配额；历史 awareness 仍迁移为 recommendation。
- 通用题不得出现监测对象或竞品别名；品牌题必须出现监测对象。
- 只使用已经确认的对象、别名和域名，禁止自动增加竞品或正式别名。

## 确定性规则

### 有效回答

将失败、pending、空回答、登录页、报错、拒答和占位内容保留在明细中，但排除在业务指标之外。

如果同一问题存在多次采集，选择最早的有效 repeat 进入报告；其余 repeat 继续保留在审计数据中。

### 提及与顺序

对原文和别名执行 Unicode NFKC、大小写归一、词边界和最长别名匹配。例如别名 `Apple` 不得命中 `pineapple`。

将 `mention_order` 和 `report_rank` 设为回答中已配置对象的首次出现顺序；保持 `recommendation_rank=null`。该顺序不代表语义推荐排名。

### 指标公式

- 提及率：通用问题有效回答中提及对象的回答数 ÷ 通用问题有效回答数。
- 声量占比：每个对象在每条通用有效回答中最多计一次，再除以全部已配置对象的提及次数之和。
- 平均顺序：`report_rank` 之和 ÷ 提及该对象的通用有效回答数。
- 总览正向情绪占比：正向 ÷（正向 + 负向），中性不进入分母；分母为零时展示 `—`。
- 品牌表达完整分布：正向、中性、负向分别除以所有已完成情绪判断的监测对象提及回答数。
- 品牌官网引用占比：监测对象官网的原始引用记录数 ÷ 所有入选有效回答的原始引用记录数；该指标不去重。
- 来源类型占比：按 `(answer_id, canonical_url)` 去重后再聚合。
- 热门域名和页面：按不同回答 ID 数量计数，先按数量降序，再按域名或 URL 升序，最多展示八项。

在内部保存分子、分母、原始值、展示值和相关记录编号。仅在展示阶段使用 `ROUND_HALF_UP` 舍入。

### 机会分档

只处理具有有效回答的通用问题：

- 未提及监测对象 + 推荐、比较或决策意图 → `priority_improve`。
- 已提及监测对象 + 顺序大于等于 4 → `continue_optimize`。
- 已提及监测对象 + 顺序为 1 至 3 → `stable`。

按 PRD 固定排序，每档最多展示三条。

### 行动状态

当至少存在一条有效通用回答时生成品牌进入方向：

- 最优竞品提及率减去监测对象提及率大于等于 10 个百分点，或优先改进问题占比大于等于 20% → `absent`。
- 否则，监测对象平均顺序减去最优竞品平均顺序大于等于 1.0 → `position_lag`。
- 其他情况 → `no_significant_gap`。

当至少存在一条原始引用时生成引用证据方向：

- 品牌官网引用占比小于 10% → `weak`。
- 品牌官网引用占比大于等于 10%，且官网页面数小于等于 2 → `insufficient_coverage`。
- 其他情况 → `stable`。

当至少存在一条已完成情绪判断的监测对象提及时生成品牌表达方向：

- 负向表达占比大于等于 15% → `risk`。
- 否则，正向表达占比小于 50% → `flat`。
- 其他情况 → `positive`。

## 来源类型

只允许以下八种内部枚举：

1. `brand_official`：品牌官网
2. `competitor_official`：竞品官网
3. `media_review`：媒体评测
4. `ugc`：用户生成内容
5. `corporate_site`：企业网站
6. `encyclopedia_reference`：百科与参考资料
7. `institutional`：机构网站
8. `other`：其他来源

仅当 `host == official_domain`，或 host 以 `.` + `official_domain` 结尾时，判定为对应官网。

## 发布门禁

以下情况阻断发布：配置无效或未冻结、配额不符、有效回答为零、混入其他 run 的产物、监测对象情绪未解决、指标不变量失败、仍有 pending 任务、五个报告模块未解决、必要行动任务未解决，或缺少追溯哈希。

以下情况允许显式降级：未知来源无法分类、没有高频主题、模块分析文案失败、行动文案失败。降级时仍保留确定性数据，禁止写成业务零值。

## PRD 已知歧义

- 首次出现顺序不等于推荐顺序。本实现公开两者差异，不用“排名”掩盖语义。
- PRD 未明确未配置品牌是否进入顺序计算。本实现只对冻结的监测对象和正式竞品排序，并在审计文件中记录该政策。
- 完整 eTLD+1 解析通常需要 Public Suffix List。纯标准库核心使用常见多级后缀表完成热门域名展示聚合；正式官网匹配始终使用精确规则，不受影响。
