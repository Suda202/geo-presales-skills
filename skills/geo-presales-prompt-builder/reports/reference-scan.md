# Reference Scan

## Anchor

现有 `yao-geo-intent-miner` 提供双层意图、五段式重写、追问链路、证据状态与聚类方法；Peec AI 售前报告审计提供了海外生问的真实失败样本。

## External benchmarks

- Google Natural Questions：使用真实 Google 用户问题，说明真实查询可能很短、大小写或语法并不统一；不应设置人为词数下限。
- Apple QReCC：把上下文依赖问题重写成可独立检索的问题，支持将 `user_question` 与 `standalone_rewrite` 分开。
- Microsoft MS MARCO：基于匿名真实 Bing 查询，并单独处理 well-formed 表达，支持“真实表达 + 可回答性/完整性门禁”，而不是只生成理想化长问题。

## Borrow

- 真实问题优先，不把文章标题当问题。
- 多轮问题必须保存原问与上下文独立重写。
- 生成问题代表意图空间，必须用真实查询、销售/客服数据或平台采样继续校准。

## User reference · 2026-07-27

`海外GEO售前Prompt生成_国内逻辑参考与配额改造_V0.1.md`（正文 V0.3）提供了当时采用、后续已由 2026-08-13 规则部分替代的约束：

- 当时保留 40/10 与 12/25/13 交叉配额；2026-08-13 后只保留 40/10，三类意图改为都有即可。
- 当时默认 5 条 Branded Comparison 使用三个正式竞品逐一覆盖加两条关键因素/多品牌题；现在只在实际达到 5 条时触发 3+2。
- 先生成目标人群、核心场景和选型因素；当时采用的受众硬配额已被后续规则取消。
- 价格随公开套餐、定制报价和真实选型需要动态生成，不设固定题量。
- 竞品自动补足先看同一次购买选择的可比性，再在同一可比等级内优先细分品类头部。

## User reference · 2026-08-13

多轮 BPI-81 审计后，正式规则更新为：

- 商业意图只有推荐、比较、决策，不再生成了解类。
- 每条问题必须围绕所属 Topic，独立体现品类，不能使用跨行业占位词。
- Generic 的合理答案必须命名具体品牌/供应商/产品候选；纯科普、纯材料区别、评估框架、购买流程和不涉及候选的品类取舍不合格。
- 一题一意图按条件类型和取值判断；句式重复与 Yes/No 不机械判错。
- 目标用户是条件来源，不设逐受众最低配额；`best/top` 等商业问法不设硬比例。
- 四类条件来源是目标用户、评估标准、约束、比较对象；它们不与三类意图机械一一对应，最终按答案终点归类。
- 每个 Topic 在 Branded 中固定加入 1 条 `Evaluate the {品类} company/product {品牌} on {主题}`，硬归 Decision，不新增情绪意图字段。
- BPI Task 89 暴露了两类可复用失败：购买对象从 OEM/ODM 电池制造商漂到热管理厂商、集装箱式储能系统商或 500 MWh 项目合作伙伴；标签虽写 Recommendation，问题却只问采购知识，回答不会稳定给供应商候选。

## Do not borrow

- 不把 QA 数据集的答案抽取任务搬进本 Skill。
- 不因为真实查询可能是短语，就允许检索词直接进入售前监测。
- 不引入与当前问题生成无关的大型评测框架。
- 不引入国内弱/中/强、T1–T4、固定场景模板或 DART 分数；答案终点只作为生成与 review 规则。

## Local fit

首版优先解决已出现的损失：题量缺失、标题/关键词混入、购买/注册裸命令、品类或购买对象漂移、假商业意图和同条件换措辞。
