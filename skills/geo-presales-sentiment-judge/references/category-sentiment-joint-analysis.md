# 品类认知与品牌情感联合分析

对应设计的 4.6。Category Awareness 回答给出「AI 认为这个品类最重要看什么」,品牌情感给出「AI 对本品/竞品在这些方面形成了什么认知」,两者在 **Theme 层对齐**后即可判断:品牌认知是否覆盖了 AI 重视的标准。

## 输入与输出

| 输入 | 回答的问题 | 输出 |
|---|---|---|
| Category Awareness Theme | AI 认为当前品类最重要的判断标准是什么? | 品类核心标准及其证据原文 |
| 本品 Sentiment Theme | AI 对本品在这些标准上的认知是什么? | 已建立的正向认知、负向风险、暂未形成明确认知的 Theme |
| 竞品 Sentiment Theme | 本品与指定竞品在相同标准上分别形成了什么认知? | 同一 Theme 下的竞品情感矩阵 |

## 对齐规则

- **Theme 对齐用语义归一,不要求原词完全相同**。「价格不透明」与「定价不清晰」是同一 Theme。
- 三张表必须用**同一套 Theme 定义**——这正是 [Claim 层契约](claim-layer-contract.md) 要求 Theme 保持中性的原因:Theme 一旦带方向(如「价格透明度低」),就无法与品类标准对齐。
- **只有 Category Awareness 或情感回答中存在可回查证据时才能形成判断**;证据不足时显示「**暂未形成明确认知**」,不推测、不补值。
- 开放竞品不进这张联合分析(它只在提问明细层保留)。

## 输出与去向

联合分析的结论进入客户报告的 **04 情感与品牌认知**,并作为 **05 内容规划**的输入:

- 「已纳入」→ 该标准下品牌已有正向认知,内容侧做强化与多点复用。
- 「缺失」→ AI 重视但品牌未建立认知,内容侧优先补事实承载页。
- 「冲突」→ AI 形成的是负向认知,需要事实框定与重构(不否认真实短板)。
- 「证据不足」→ 显示暂未形成明确认知,不写成结论。

## 与 Theme 矩阵的关系

联合分析的展示形态包含「同一 Theme 下各品牌的情感认知对比」,即 Theme × 品牌的矩阵——单元格展示的是**该主题下的 Attribute 描述**(带方向),不是数字。这与当前报告里 `theme_matrix` 的形态一致,区别只在于数据源:旧形态来自 claim 标签的关键词归一,新形态来自 Claim 层的 Attribute 归一,**新形态更准**(不依赖关键词命中,漏标签的问题消失)。
